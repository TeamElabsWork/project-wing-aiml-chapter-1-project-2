## Policy notes

* Sketchfab downloads must be `downloadable = true` and carry CC0 / CC-BY or an explicit
  project-use licence visible on the asset page. Anything flagged NC, ND or "editorial use"
  is rejected.
* Fab/Marketplace assets are recorded with the purchase/claim receipt reference.
* Engine Content (e.g. `/Engine/BasicShapes/*`) needs no row, but **must not be duplicated and
  rebuilt** — reference it or build new geometry procedurally instead.
* On every import, the licence text/URL is copied into this file, not just linked, so the
  register survives if the source page disappears.
* Sketchfab-sourced meshes are delivered from Blender as GLB into `Saved/Import/` and imported
  with Interchange. Interchange splits a GLB into one asset per material, so each import is
  recombined into a single static mesh with per-material sections; the split parts are not kept.
  The GLB files themselves live outside `Content/` and are therefore not version-controlled assets.
